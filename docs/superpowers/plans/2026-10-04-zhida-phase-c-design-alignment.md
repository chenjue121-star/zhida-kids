| 放弃调整 | 直接恢复旧 source_snapshot | 先读最新共享内容；成功后才放弃草稿并从最新方案开始；读取失败保留原草稿 |

| 分时安排 | 原始孩子编号、无明确时段选择、来源变更时可沿用旧表单 | 上午／下午／全天；全具体来源及主备用途；过期确认不称已确认；来源范围变化关闭暂存表单并要求重核；晚回包检查展示范围 |
| 保存前使用变化 | 看不到本套保留／新增／不再使用内容 | 显示保存成功后的本套使用差异；说明其他方案的引用仍保留；不提前宣称释放、穿过、归还或洗好 |
| 天气与冲突 | 权威核对天气未同步、任意 409 都称家人更新 | 使用本次核对天气；有效天气变更重新确认，时间戳刷新不误清确认；只有 VERSION_CONFLICT 提供家人对比 |
| 原保存恢复与历史成功 | 成功／待确认缺主备原内容，后续最新方案混入历史 | 原提交照片、当时选定主备与分时；当前提醒和家人后续方案独立展示；不重新选定或覆盖最新方案 |
| 弹层及异步保护 | 选中不可读、背景滚动、旧照片／成员在重载中可回填 | 圆形浅绿选中、可读选中标签、44px 按钮、标题／关闭／取消、80vh 上限；列表内部收缩滚动、底部操作稳定可见；独立请求守卫；登录／撤权即时清理 |
| 保存未知的范围 | 同家庭同日的另一宝贝也被阻断 | 按身份、家庭、孩子和实际日期定位待确认保存；不同孩子独立保存；旧日期键按原 payload 或历史 response.plan 恢复，保留原位置与原操作 |
| 撤权后的结果查询 | 旧结果缓存和微任务续体可重新显示成功内容 | 无家庭访问权拒绝读取 pending／历史缓存，清除未知标记；回包继续处理前同时检查页面和权限；合法仅查看成员仍可查询历史 |
| 定位不可用 | 微信不回定位 callback 可阻断实际日期载入 | 5 秒超时后继续获取家庭目标日上下文，天气未知按未知流程展示 |
