本轮没有调用真实 Qwen／ARK，没有项目准确率、实际 token 成本、模型胜负或家长确认负担结果。测试中的 provider 为 FakeProvider/MockTransport/缓存夹具，不能当作实际 API 效果。没有替用户提交或合并已有改动。
