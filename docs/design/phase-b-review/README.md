## 已有产品要求

1. 当前孩子是本批默认归属，开始拍摄前可选；集中确认时可以批量改归属。
2. 连续拍照不等待识别，相册支持多选；默认一张一件，允许多件图。
3. 类型、颜色、图案自动识别；厚薄或不确定信息集中核对。品牌、价格不是入库门槛。
4. 多件图展示候选，由家长选择拥有的实物。保留原图和候选对应，确认接口才建立衣物。
5. 保存前明确告知默认合身、可穿，只改例外。
6. 同图复用上传资产，不能据此认定是同一件实物；不同照片疑似重复只提示，同款多件不能自动合并。
7. 图片与待确认进度保留，识别局部失败支持重试或手填；已经确认成功的衣物不重复新建。
8. 衣橱支持网格、筛选、详情、编辑、移除、状态、共用和转交。
9. 合身是“孩子与实物”的关系；待洗、找不到等属于同一件实物的共享状态。
10. 仅查看成员只读衣橱，不可上传、识别或保存；失去家庭权限后不得继续读批次结果。

推荐生成、天气、固定单品搭配、备用和按日期占用属于 C；反馈学习、搭配日历和上线验证属于 D。

待洗、找不到为同一件实物的共享状态，不能因换归属清除。合身属于每个孩子各自关系，新使用者不能直接继承原孩子的合身结果。所有新选择目标限定同家庭、未归档孩子。

移出采用可恢复归档，与可穿／待洗等实物状态分开。恢复需展示上次归属、合身和状态，核对后恢复；若原宝贝仍有效可以保留原关系，但需确认当前合身。原宝贝已归档则不重建其使用关系，也不恢复孩子档案；无有效使用者时必须重新选孩子。恢复不自动将待洗改为可穿。

### 选中状态调整（用户反馈后，v2，待确认）
