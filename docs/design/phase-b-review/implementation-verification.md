## 已实现

原生小程序新增 wardrobe、intake、intake-confirm、garment-detail、garment-edit、garment-owners、wardrobe-removed 七页，首页与我的接入三入口导航。白底、品牌绿、独立居中下拉标记、柔和圆形选中态和 44px 控件沿用已讨论方向。

后端 v2 新增家庭实物、孩子独立合身、私有媒体、本人批次与候选、操作账本和持久任务；0003 迁移已应用到专用开发库。确认才建立实物，换操作身份也不能重复创建同一候选。使用已有、共用、转交、移出／恢复均保留同一物理 ID；恢复使用最近一次移出关系快照，每位有效孩子重新确认合身。

连续拍摄和两路照片上传可以并行，单项失败可续传或在同图继续手填。迟到识别只增加未选的候选，不覆盖人工字段；成功零候选不会伪造衣物或触发模型重试。Qwen／ARK 适配器已有注入测试，实际配置缺密钥时展示真实未配置结果。

未知提交查询独立于新选择，查询不能转为新写入。resolve 以同一操作身份和原 payload 在家庭锁内落终态，挡住迟到提交。单项 savepoint、实物变化和结果账本共事务，部分成功仅允许明确失败项重试。权限与版本在执行及重放时重查，媒体在存储读取后也二次鉴权。
