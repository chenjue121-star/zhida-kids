今天建议

01 / 快速决定

打开就有一套建议。可换回上一套、调场景与偏好，未选不保存。选定后查看同日同组合；备用与固定单品入口按需展开，详细调整留在后续组。

准备明天

02 / 独立日期

明天示例选择户外。首次场景仍为日常；本版用周日户外例子呈现明天候选，选定独立，不覆盖今天。本组提案：场景按孩子与日期保留；已有规格仅确认每个孩子最近场景，待本轮确认。

已选方案

03 / 家人有据可看

清楚保留谁选、哪一天、哪一套。天气更新提示不改写原方案。“修改这套 / 新增一套”分别进入后续组的编辑设计，本版只说明，不模拟保存成功。

切换孩子

04 / 状态跟着孩子走

姓名、年龄与当天状态一起选。切换后可见该孩子自己的候选、偏好与已选；切回保留原状态。弹层可关闭再开，圆形勾选沿用 B 阶段。

本组讨论决定

提案：默认直接给一套，以“换一套”逐次比较；场景与偏好按需调整。已选方案保留选定时的衣物和依据，后续天气与偏好变化只提示。偏好来源可选家庭、当前成员或指定成员；本组只确认入口与信息表达。

方案日常体验本轮取舍
推荐 · 直接给一套打开即可判断，要改再展开。采用；保留“换一套”。
多套横滑选择更容易比搭配，也增加每日决策负担。暂不作为默认。
先填完整条件条件更明确，但拖慢每天打开的节奏。改为按需调整。

后续分组：② 替换与固定；③ 备用与一天多套（修改 / 新增）；④ 共用占用；⑤ 异常与保护。日历与历史属于 D 阶段。逐组确认 HTML UI 后，才进入 C 阶段实施。
